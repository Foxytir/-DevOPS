# probe-stack

Учебный сервис для домашнего задания № 2 по дисциплине «Инструменты DevOps».
Тот же `probe` с заметками в базе, что в четвёртой лабораторной, но с драйверами
`psycopg2` и `mysqlclient`: при установке они компилируются из исходников,
поэтому образ собирается в два этапа.

## Что умеет

| Метод и путь | Что отвечает |
|---|---|
| `GET /` | строка со словом-маркером и именем хоста |
| `GET /me` | JSON: ФИО, группа, слово-маркер, имя хоста, версия, к какой базе подключено приложение |
| `POST /notes` | записывает заметку из поля `text`: `curl -X POST <адрес>/notes -d text=...` |
| `GET /notes` | все заметки из базы |

Таблицу `notes` приложение создаёт само при первом обращении.

## Запуск

На машине с одним только Docker:

```
bash deploy.sh 5.0
```

Скрипт сам включает режим Swarm, поднимает свой реестр на порту 6004,
собирает образ с версией `5.0`, отправляет его в реестр и разворачивает стек
`akhmetov-04`: три реплики приложения и MariaDB в своей сети 10.24.0.0/24.
Публикация — на порту 8012. Новая версия выкатывается той же командой:
`bash deploy.sh 5.1` — без остановки старых реплик и без потери заметок.

## Переменные окружения

| Переменная | Что задаёт | По умолчанию |
|---|---|---|
| `DATABASE_URL` | адрес базы: `mysql://root:lab@db:3306/lab` | нет, без неё `/notes` отвечает 503 |
| `MARKER` | слово-маркер в ответах | `runlab` |
| `APP_PORT` | порт внутри контейнера | `5004` |

## Версия

Читается из файла `/app/VERSION`, который пишется при сборке строками
`ARG VERSION` и `RUN echo "$VERSION" > /app/VERSION`. Нет файла — `dev`.
Каждая заметка хранит версию, которая её записала.
